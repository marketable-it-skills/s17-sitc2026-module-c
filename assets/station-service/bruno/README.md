# Station Service Bruno collection

1. Start the Station Service from the parent directory with `npm run dev`.
2. Open this `bruno/` directory as a collection in Bruno.
3. Select the `Local` environment.
4. Run the collection in sequence.

The collection is repeatable and covers:

- listing all QR-code records;
- selecting and retrieving an active QR payload;
- selecting and retrieving a disabled QR payload for negative-path simulation;
- rejecting an unknown QR identifier;
- rejecting an invalid request body.
